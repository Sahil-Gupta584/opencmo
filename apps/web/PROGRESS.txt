# OpenCMO Reddit Growth & Marketing Platform - Progress Tracker

**Strategy & Execution Model**: 
> [!IMPORTANT]
> **No Direct Reddit API Posting**: Due to strict Reddit API rate limits, OAuth complexity, and shadowban risks, the platform strictly focuses on **AI Research, Subreddit Discovery, Opportunity Radar, and Ban-Safe Content Generation**. Users manually copy and post content to Reddit directly.

---

## Feature Matrix & Implementation Status

| Feature Area | Ideal Planned Requirement | Current Codebase Implementation | Status |
| :--- | :--- | :--- | :---: |
| **Auth & BYO-AI Setup** | Secure Auth + AES-256 encrypted API key storage (OpenAI/Anthropic/Gemini) | Better-Auth + `UserApiConfig` with AES-256 encryption (`src/lib/crypto.ts`) | ✅ |
| **Website Scraper** | Scrape user product URL for metadata, keywords & target audience | `scrapeWebsite` parses title, description, and body text (`src/lib/scraper.ts`) | ✅ |

| **Ban-Safe AI Content Drafter** | Generate subreddit-tailored post drafts with spam risk score | AI drafting with link density risk scoring (`src/orpc/router/projects.ts`) | ✅ |
| **Dynamic Daily Roadmap** | Custom multi-day engagement action plan per SaaS niche | Currently uses basic static template task items | ⏳ *In Progress* |
| **Intent Scoring Algorithm** | Real AI-evaluated intent rating per thread | Currently uses placeholder heuristic randomizer | ⏳ *In Progress* |
| **No-API Direct Posting** | Manual user copy/paste execution (No auto-posting / No API write risk) | Intentionally designed for manual posting by user | ✅ |
